A PLATAFORMA

Azure Pipelines e a alternativa executada

Escolha inicial: Azure Pipelines

Serviço de CI/CD da Microsoft, dentro do Azure DevOps.

Atende diferentes linguagens e integra repositórios como o GitHub.

Arquivo preparado:
azure-pipelines.yml

Demonstração: GitHub Actions

Automação do GitHub, integrada ao repositório.

Usamos a alternativa após a restrição de acesso ao Azure.

A substituição depende de acordo com o professor.

FUNCIONAMENTO

O que dispara e executa o pipeline

GatilhoPush em main, pull request ou execução manual.

WorkflowArquivo YAML versionado com a sequência de trabalho.

JobGrupo de comandos com dependências e resultado próprio.

Runner ou agenteMáquina que instala dependências e executa comandos.

No fluxo executado: GitHub Actions, Ubuntu 24.04 e Node.js 22.
