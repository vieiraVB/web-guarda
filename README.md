# Web Guarda

Plataforma web para inclusão digital e conscientização sobre segurança na internet.

## Sobre o projeto

O Web Guarda é uma plataforma web educativa desenvolvida como projeto
interdisciplinar de extensão do curso de Ciência da Computação.

A plataforma tem como objetivo contribuir para a conscientização dos
usuários sobre segurança digital, abordando temas como phishing, golpes
virtuais, engenharia social, senhas seguras, páginas falsas, malware,
proteção de contas, privacidade e proteção de dados.

## Objetivo

Desenvolver uma plataforma web educativa que auxilie os usuários na
identificação de ameaças virtuais e na adoção de práticas mais seguras
durante o uso da internet.
